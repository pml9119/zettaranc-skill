## 二、⚠️ 工单原方案已被推翻（重要）

工单原文的两条硬约束之一：

> 🔴「**本会话无法视觉读图**」—— 探针图只回传元数据 → **不能靠看图蒸馏，也不能描述 Z 哥在图上的标注**

**实测：❌ 该判断是错的。** `read_image` **完全可用**，已产出三份语义级读图 + 像素级取色。

**且视觉读图产出了「数据重建永远做不到」的三件事**：

| # | 产出 | 为什么纯数据重建做不到 |
|---|---|---|
| 1 | 🔴 **发现并修复 `zg_white` 公式 bug**（周期 10 → **12**） | 重建用的是**我们自己的错误公式**，只会"自洽地错" |
| 2 | 🔴 **确定「黄砖 = 砖买入信号」语义** 并实现三态 | 图上信息，数据里没有 |
| 3 | 🔴 **三组形态分类 + v2 判据结构** | 同上 |

**→ 原方案的 `rebuilt_image`（重画图）已失去动机**（原图可直读）；
**但其「数值重建 + 自动比对」的实质已经完成** —— 就是那 210 项校准，**已固化为 `ref-images-index.tsv`**。

## 三、`ref-images-index.tsv` 字段

| 列 | 说明 |
|---|---|
| `id` | `b2-01` / `b1-01` / `brick-01` |
| `code` / `name` / `date` | 标的与信号日（**日期以图上光标为准，非文件名** —— 见 `note`） |
| `group` | `B2` / `B1` / `brick` |
| `class` | 组内分类（B2：A/B/C/D；B1：a/b/特殊；brick：浅/中/深） |
| **`short_line`** | **我们用当前代码算的短期线** |
| **`img_short_line`** | **图上标题栏打印值（真值）** |
| **`verdict_short`** | `match` / `mismatch` |
| `dg_yellow` / `bbi` / `ma6` / `kdj_k` / `kdj_d` / `kdj_j` | 我们算的另外 6 项 |
| `others_verdict` | 该组另外 6 项的**组级精确计数**（逐项明细见 `ref-images-calibration.md`） |
| **`note`** | 该条的已知异常 |

### ⭐ 当前 verdict 汇总

| 指标 | 结果 |
|---|---|
| **短期线（`short_line`）** | ✅ **30/30 `match`** —— 用**修复后**的 `EMA(EMA(C,12),12)` |
| 另外 6 项（组级） | BBI 29/30 ｜ MA6 28/30 ｜ 多空线 26/30 ｜ K 24/30 ｜ D 25/30 ｜ J 25/30 |

> **索引生成方式（可复跑）**：脚本从 `daily_kline` 取 K 线 → 截到信号日（**防前视**）→ 调用
> `modules.indicators.price_patterns.calculate_zg_white` / `calculate_dg_yellow` / `calculate_kdj` → 与图上值比对。
> **即：索引由活代码生成，不是手工填的。**
