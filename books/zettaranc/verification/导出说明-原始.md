## 图片命名规则

`序号_日期_股票代码_股票名称_标签.png`

- 同一条目配多图时追加 `-1`、`-2` 后缀
- 原文未标注买卖的条目用 `未标注` 占位
- 文件名中的日期/代码/名称/标签均取自该条目所在段落，便于与 CSV 对齐

## 字段说明

| 字段 | 含义 |
| --- | --- |
| 序号 | 按文档正文出现顺序编号（1–65） |
| 日期 | 归一化为 YYYY-MM-DD |
| 日期原文 | 文档中的原始写法（部分为 8 位或 9 位数字） |
| 代码 / 交易所 | 6 位股票代码与 SZ/SH/S 后缀 |
| 名称 | 股票名称 |
| 标签 | 买 / 不买 / 卖 / 不卖 / 可买可不买（空=原文未标注） |
| 关键标注 | 标题中的信号词，如 b1、+砖、+非绿柱、不碰 |
| 理由 | 标题中标签之后的文字 + 后续说明段落，合并去空白 |
| 原文 | 该条目全部原始文字（含换行），未做任何删改 |
| 图片文件 | 对应图片文件名，多张用 ; 分隔 |
| 图片数 | 该条目配图数量 |
| 备注 | 导出过程中的数据提示（见下） |
