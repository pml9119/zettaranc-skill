## 一、as-of 路径（**必须自建，`detect_all_strategies` 没有 `as_of`**）

`detect_all_strategies(ts_code, days=120, klines=None)` 签名无 `as_of`，且**扫描传入窗口内的每一天**（不是只看最后一根）。

**采用的路径**：

```python
kl = get_kline_data(ts, 800)                            # 取全历史
w  = [k for k in kl if str(k["trade_date"]) <= asof]     # 截到信号日（防前视）
sig = detect_all_strategies(ts, days=len(w), klines=w)
```

**三重验证**：

| # | 验证 | 结果 |
|---|---|---|
| ① | 截断边界：65 条全断言 `last_date == as_of` | **65/65 通过**；as_of 日在 DB 都有**精确 bar** |
| ② | 单日归约等效性：包装器 == 未包装折叠（两种后处理）在 seq 6/22/14 上对照 | **三者集合完全相等 3/3** |
| ③ | **防前视硬验证**：把序列停在 k vs 延到 k 后 204/87/320 根，同一 k 上跑全部 19 个日线探测器 | **结果逐个完全相同**；KDJ/BBI/白线/黄线/砖值/麒麟阶段也全同 → **探测器本身因果** |

> ⚠️ **唯一例外 = `macd_dif`** —— 不是探测器越界，是折叠入口自身的错位 bug，见 §六。**已修**。

**后处理去重会隐藏信号日触发**：`StrategyType.B1` 被 **4 个来源复用**（`detect_b1` / 三波理论·建仓波 / MACD死叉多 / 关键K-B1），`_post_process_signals` 按 `(日期, 类型)` 去重 → **65 条里 19 条（29%）**当天真实触发的探测器在用户可见输出里消失。
