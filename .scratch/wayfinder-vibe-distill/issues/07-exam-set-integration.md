## Question

用户提供 `考试测试集.docx`（11.2 MB），对应语料场次 **`20260429 三种常用战法摸底考`**。用什么形式加进蒸馏？

## Answer（方案已出，待批准）

### 素材实况（实测）

| 项 | 值 |
|---|---|
| 结构 | 段落 131（正文区 133 行）／图片 64／表格 0 |
| 解析出的案例 | **65 条** |
| 带 Z 哥口述理由 | **62 条** |
| **标签分布** | **不买 25 ｜ 买 25 ｜ 不卖 7 ｜ 卖 4 ｜ 可买可不买 2 ｜ 空 2** |
| 时间跨度 | 2024-10 → 2026-04（**完全落在本地 DB 覆盖内**） |
| 图片对齐 | **成功** —— image N 紧随案例 N（`exam-image-map.tsv`） |

### 推荐形式：**双重身份**

**① 验收集（eval set）★最重要**
项目 `modules/verify/` 此前只有**五项硬门**（Sharpe/Calmar/胜率/MaxDD/OOS-IS），全部来自回测统计量，**没有任何人工标注的判定真值**。本套是**首份**。
→ 对 65 条跑 `detect_all_strategies(ts_code, as_of=date)`，与 Z 哥标签比对 → **混淆矩阵（买侧/卖侧 的命中、漏报、误报）** → 30+ 探测器首次有可量化准确率，同时是 02 号 F2 探测器验收的客观依据。

**② 案例库（E 段素材）**
62 条带口述理由 → 喂 cangjie 的 **case-extractor** → 落进各能力卡 **E（例子）段**。
理由分布直接印证 01 v3 的缺口：大量「不买/卖」理由是 **黄线之下 / 阶梯量出货 / 三波不做 / 跳空 / 无序 / 蜈蚣图 / 量价背离** → 对应 **M3 缺口（五种出货 0 篇、阶梯量 1 篇）** 与 **M4 量能族缺口**。
新术语需入 GLOSSARY：**蜈蚣图 / 无序 / 三门重炮 / 砖兑水板 / 面积（阴阳量面积比）**。

### 不建议

- 当普通语料段叙述性蒸馏 → **丢掉标签的结构化价值**（无法统计准确率）
- 只做知识文档 → 同上
- 把 64 张图写给 LLM 描述 → 不可复现 + 幻觉风险；图可由数据重建（见 08 号）
