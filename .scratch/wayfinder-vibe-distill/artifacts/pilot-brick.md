## 二、RIA 能力卡：砖型图（专精图）三种定式

> `capability_id` 建议：`zettaranc-brick-three-patterns`｜模块归属：**M1 买点**（骨架出处：`E:\Z哥逐字稿\20260415知行交易模块总结`，原话「砖形图（专精图）」）

### R（规则）

1. **砖型图是把价格行为压成红/绿「砖」的动量图**：判定只用砖值序列的相邻比较——**今天红柱 = 砖型图 > REF(砖型图,1)**；**昨天绿柱 = REF(砖型图,1) < REF(砖型图,2)**（`砖型图.txt:11-12`）。绿转红即为一组结束，「重新数砖，一二三四」（`0318回放3 00:00:00`）。
2. **计数单位是「砖」不是 K 线**：「这个砖你就按下面砖数，你别按上面K线数」（`0325回放2 01:16:04`）；翻红重数红砖、翻绿重数绿砖。
3. **四块砖铁律（卖出侧骨架）**：①数四块红砖之后 → 减仓或清仓，注意随时反转；②红砖收盘前三分钟变绿就走（**仅限 A 股**）；③买入后不涨（= 平盘或亏损）→ 次日九点半开盘后无大幅拉升，9:33/9:37 全走（`0318回放3 00:33:36`、`00:34:04`、`00:35:28`–`00:35:56`、`00:38:16`）。
4. **本质是「卖」与「买入后的应对」**：「D S Z Trading Strategy最核心的、最重要的那个点是哪个？…卖」（`0318回放3 01:22:08`–`01:22:36`）；「看票这个事儿…就是没有意义」（`0318回放3 01:21:12`）。买入侧允许「任何位置买一手赌反包」，**胜负由应对决定**（`0318回放3 01:23:04`）。
5. **命名同一性**：专精图玩法 = 「大傻子交易法」→「**DSZ 战法 / DSZ Trading Strategy**」，亦称「板砖战法」「打胜仗战法」（`0318回放3 00:55:32 / 00:56:56 / 01:00:40 / 01:01:08`）。

**公式语义（`砖型图.txt` 28 行，逐行实读）**

```
VAR1A := (HHV(HIGH,4)-CLOSE)/(HHV(HIGH,4)-LLV(LOW,4))*100-90
VAR2A := SMA(VAR1A,4,1)+100
VAR3A := (CLOSE-LLV(LOW,4))/(HHV(HIGH,4)-LLV(LOW,4))*100
VAR4A := SMA(VAR3A,6,1)
VAR5A := SMA(VAR4A,6,1)+100
VAR6A := VAR5A-VAR2A
砖型图 := IF(VAR6A>4, VAR6A-4, 0)          // 主图副图值，源码 COLORRED
今天红柱  := 砖型图 > REF(砖型图,1)
昨天绿柱  := REF(砖型图,1) < REF(砖型图,2)
红柱高度  := 砖型图 - REF(砖型图,1)
绿柱高度  := REF(砖型图,2) - REF(砖型图,1)
高度达标  := 红柱高度 >= 绿柱高度*2/3
黄柱      := 今天红柱 AND 昨天绿柱 AND 高度达标   // STICKLINE(...COLORYELLOW)
红柱      := 今天红柱 AND NOT(昨天绿柱 AND 高度达标)
绿柱      := REF(砖型图,1) > 砖型图
AA := REF(砖型图,1) < 砖型图 ; CC := REF(AA,1)=0 && (AA=1) ; XG := CC>0
```

**信号条件编号**（供回测卷映射布尔条件。⚠️ 刻意用 `F` 前缀，避开体系里 `S1/S2/S3` = 逃顶卖出信号，勿混）
- **F1 翻红**：`brick_t > brick_{t-1}`（对应 `XG = CC>0`，即**首次**翻红）
- **F2 昨绿**：`brick_{t-1} < brick_{t-2}`
- **F3 高度达标**：`brick_t - brick_{t-1} >= (brick_{t-2} - brick_{t-1}) * 2/3`
- **F4 黄色（黄金）柱**：`F1 ∧ F2 ∧ F3`
- **F5 红转绿**：`brick_t < brick_{t-1}` 且 `brick_{t-1} >= brick_{t-2}`（= `is_brick_flip_green`）

- 活跃市值**空头区间**：只卖不买、去弱留强；要做只能「台费」小仓，且**先控制仓位、先练级**（`0325回放4 00:02:48`、`00:04:12`）。
- **空头趋势翻红只能赌一把，翻绿不信也得信**（`0325回放2 01:18:24`）。

**A2.2 买入**
- 时点：**红砖第二块的早盘买入**（`0318回放3 00:40:36`）；选股完成**次日开盘买，不盘后买**（`0325回放2 01:43:08`、`0318回放3 00:41:04`）。尾盘买 vs 早盘买「回测…没有特别明确的胜率」，属个人习惯（`0318回放2 00:24:16`）。
- 组合：**与 B1/B2 共振**（`0318回放2 00:39:40`）；B2 要**不超过 4%**、不特别长；B1 离最低点仅 5–6 个点、B2 已先涨 4–7 个点（`0325回放1 01:05:48`）。
- 拒绝：不给高开 4%+ 且量比 25 倍的票打底仓（`0318回放2 00:42:56`）；不在 30 秒内追高 5 个点（`0318回放2 00:22:24`）。
- 仓位：天天轮超短「至少半仓」；试错用台费（`0318回放2 00:49:28`）；大资金因冲击成本用不了专精图（`0325回放1 01:08:36`）。

**A2.3 卖出（三句话 + 一条判据）**
1. 数满四块红砖 → **减仓或清仓**，注意随时反转；走了以后反转要认，走早了踏空也要认（`0318回放3 00:33:36`、`00:38:16`）。
2. **收盘前三分钟**红砖变绿 → 走（**仅 A 股**，不含港股）（`0318回放3 00:34:04`、`00:38:16`）。
3. 买入后不涨 → 次日九点半开盘后无大幅拉升，**9:33 / 9:37 全走**；不等红绿确认（`0318回放3 00:35:56`、`00:38:44`）。
4. 判据：**市场没有证明你对 → 你就是错的**——当天买入即被套（被套 1.5 个点），就不必再往下数砖（`0318回放3 00:18:40`「不对，那你就没必要往下再数砖了呀…是不是市场没有证明你你？」）。同义表述另见 `references/research/07-xiaocainiao-new.md:200`「市场没证明你是对的，你就错了」，**出自另一场次，非本语料逐字**。
5. S1 优先：巨量阴线一律当 S1（`0325回放1 01:06:44`）；高位震荡的**阶梯量累加 ≈ 一根或两根 S1**（`0318回放3 01:14:12`）。

**A2.4 持股与换仓**
- 数砖本身即**独立持股依据**，与白线 / BBI / 黄线并列（`0318回放1 01:23:32`「它可能是一个概率的加持…也有可能是一个持股的依据，也有可能是高位反转的一个依据」）。
- 强势票 2–4 块砖就走完，弱势票反复折腾 → 用数砖控制风险而不是死扛（`0325回放2 01:29:36`）。
- 去弱留强、低位换低位：换成**黄线位置的 B2 + 专精图**这种「带劲」的低位标的（notes 段 `0325回放2 00:32:12–00:38:44`）。

## 四、格式规范建议（供全量蒸馏）

1. **卡片骨架固定 R / I / A1 / A2 / E / B 六段**，A1 只写「怎么认」、A2 只写「认了怎么办」，B 段必须含「失效条件 / 不适用场景 / 已知限制 / 依赖的工程前提」。承 v1 建议，并新增第 2、3 条。
2. **新增「前提检查」子节（A1.0）**：凡买点类能力卡，先列不满足即放弃的门槛（本卡：白线黄线之上、离白线不远、有横盘动作、无大苗子、非跳空）。这是本轮语料最强的可执行增量。
3. **新增「工程前提」子节（I 或 B 内）**：卡片涉及自研指标时，必须显式声明**所需原语的实现状态**。本卡就是范例：序列原语缺失必须写在 I 段顶部，不能让实现者以为改个字段名就能跑。
4. **公式与语料分栏**：公式语义单独成节（逐行），把触发条件编号成 `F1..Fn` 布尔列表（**避开体系里 `S1/S2/S3` = 逃顶信号**）；并对每条条件标注**来源是公式还是语料**。本卡实测：「黄金信号」只在公式里，语料零命中——若不标注来源，后续必然被误当成 Z 哥原话引用。
5. **时间戳引文规范**：引用格式 `回放N HH:MM:SS`（逐字稿行首时间戳）；notes 分段标题给的**区间**不可当作精确时间戳，须标「notes 段」。
6. **引文 ≤150 字逐字**，ASR 明显错字用〔〕就地校正并保留原文（例：「专行图〔专精图〕」「百亿〔白线〕」），禁止静默改写。
7. **不编造标的**：语料点名 → 照写；语料只念代码 → 照写代码并标「未核实对应标的」；语料模糊 → 写「某标的」。
8. **冲突并列区**：每张卡设「语料内部 / 与官方总图的冲突」小节，并列记录、不下单方面结论（本卡见 §五 冲突记录）。
9. **diff 双表 + 编号 + ★**：已覆盖表须写「文件:行」，新内容表须写「语料出处」；已覆盖项要写清「补强了什么」，禁止只写「已覆盖」了事。
10. **检索提示入库**：把 22 项那种「术语断层 + ASR 变体」结论写进 `knowledge/` 的检索说明，否则全量蒸馏会持续漏检。
