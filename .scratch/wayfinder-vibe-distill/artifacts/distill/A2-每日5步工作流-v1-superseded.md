## 一、逐段提炼

### 1.1 正题引入（回放1 末 / 回放2 中段）
- 二楼充电课程只拿出 30%-35% 内容，市场只走约 40%，现处"慢"的阶段——市场无聊时打基本功。
- 今日正题：Z 哥每日五步极简工作流（复盘精讲版），熟练后每天 12 分钟完成，像机构一样复盘。
- 简化原则：不再要求每天一页 A4 纸式复杂复盘（普通人时间精力有限、难以坚持）。
- 对新人提醒：若还在"追涨"阶段，先走弯路再来，否则听不懂。

### 1.2 量化策略基础与择时体系（回放2 中段）
- B1/B2/B3 本质是量化策略；量化分低级/初级/高级，分享的是被验证正确的核心。
- 量化对冲策略三大模块：① 择时；② 量化对冲组合；③ 风控。
- **择时三维度**：基本面择时（双宽政策、宏观周期、康波周期）、资金面择时（成交量、存款搬家、放水、活跃市值）、技术面择时（B1/B2/B3 入场点、突破、关键 K、单针+20、站上黄线回调黄线）。
- 活跃市值是资金面的直观体现；无增量资金 → 胜率降低，要么休息，要么降仓位、玩得紧。
- 风控不仅止损，还包括"放飞"（落袋）与"滴滴"（波段止盈/止损）。

### 1.3 五步流程详解（回放2 核心）
- **第一步 择时**：只看活跃市值。底部为上涨 > 4%，顶部为下跌 < -2.3%；快则 10 秒、慢则 1 分钟判断多头/空头（晴天/阴天）。
- **第二步 定策略**：根据择时决定"满仓冲"还是"悠着点"（玩得松/玩得紧）。空头趋势下只做 B1，仓位轻（清仓/半仓/空仓）。满仓与否取决于熟练度和心理素质。
- **第三步 复盘**：快速检查持仓，逐一标注明日动作——止损、放飞、滴滴；原则上只拿白线之上的票，长线票（如队长、台子）不看；时间控制在 3 分钟。
- **第四步 选股**：每天必须选股（无论多空），用于练盘感；通过收紧条件将候选股控制在 100-300 只；只看图形，不研究 F10 和八卦，约 5 分钟。
- **第五步 执行**：开盘集合竞价后开始买卖，尾盘前（14:50-14:55）执行止损/放飞/滴滴；决策时间 1 秒到 1.2 秒，不能犹豫。
- "瞪起来一定要放飞"，如 Rita 两根涨停后必须减仓，盈利不能做亏。

### 1.4 时间配比（回放2 后段）
- 每天最多 12 分钟：择时 1 分钟、定策略 2 分钟、复盘 3 分钟、选股 5 分钟、执行 1 秒（决策）。
- 只在两个时间点干活：开盘（9:25 后）和收盘前（14:50 后）。

### 1.5 执行细节与量比开盘玩法（回放2 后段）
- 量比开盘玩法：复盘选出的 B1/B2，次日开盘看集合竞价后的量比；量比移动且大盘无恙，早盘量比动的票当天多数表现不错。
- **买入执行示例**：某票集合竞价量比 3.59 → 先"稳一手"不买；开盘一笔大单砸到 -1.6%，量比降至 3 以下 → 没戏，放弃。另一票开盘量比 3.55，第一分钟大单拉起量比升至 8.76 → 可跟进买入。
- 量比"一般不会说谎"，但存在 30% 概率出错；有效是因为跟随"铁蝴蝶"——大资金盘前定好计划，开盘即执行。

### 1.6 量比分级三档（回放2 后段，核心量化）
- **低量比开盘**（通达信 10 以下，东财减 1-3）：无大幅下跌则今日大概率震荡；强势股可能下午随大盘同步拉升。
- **高量比开盘**（20 以上最好）+ 开盘后股价上涨 → 今日大概率上攻（案例：量比 22.16 后拉涨停）。
- **高量比开盘** + 开盘后股价大幅下跌 → 先稳一手；除非带量冲破日内高点，否则大概率单边下跌或转水下震荡（案例：航天发展量比 22 先下杀，后放量突破日内高点才走强）。
- **中量比开盘**（7-16）+ 量价同步上涨 → 大概率单边上涨，较稳的买入形态。
- **中高量比 + 大幅低开**（负 2% 以上）→ 先观察；每次加速下杀出现成交量峰值时可建仓（洗盘特征）；普通投资者先不要学。

### 1.7 模拟盘全流程（回放2 后段）
- 以 10 万元为例：半仓 5 万，其中 4 万长线、1 万短线可玩；用 1 万执行 B1/B2。
- 厚普股份：昨日选出 B1，开盘量比 3.55 先不买；第一分钟量比跳至 8.76 → 立刻一笔敲入，成本低位。
- 某 B2：开盘集合竞价量比 12.03（大量比）→ 先买一半（5000 元）；突破日内高点、量比再抬头 → 剩余 5000 买入。
- 折纹案例：B1 次日开盘量比 14.6（高量比）→ 开盘即买一半；上行后再买另一半，成本 9.22 当日收 9.53；次日冲高 3.5% 以上可放飞，跌破 8.89（黄线）止损，跌破当日最低价则滴滴。
- 已持仓若低开 23 倍量比但不大幅下杀 → 继续持有等待放飞；没破位不动。

### 1.8 大盘研判与"玩得紧"（回放2 末）
- 当前活跃市值空头区间，反弹极弱（连 2% 都没有），大盘打到黄线压制。
- 关键位置：下方约 2.45 万亿融资盘；若明天大阴线跌破低点可能引发踩踏，行情结束。
- 大概率双底：周四五回踩确认前低，形成双底再反弹；单底不是底。
- 用 MACD 判断波段调整：MACD 从零轴上穿下零轴，越往下越接近底部；当前约 -3.88，若到 -5 附近（接近前低极值）配合融资盘与双宽，调整大概率到位。
- 允许一根阴线但幅度在 1% 以内；超过 2.6% 大阴线破坏结构、救不回来。
- 操作：当前"玩得紧一点"，只做 B1 且轻仓；等二次探底确认后再行动。

## 二、RIA 能力卡（五日工作流 SOP）

### R（规则）
每日 5 步标准化复盘 SOP（总时长 ≤12 分钟）：**择时 → 定策略 → 复盘 → 选股 → 执行**。把专业量化降维成散户每天能坚持的固定流程，核心是让"何时该干什么"有明确答案，不让盘中情绪主导。每日只在开盘（9:25 后）与收盘前（14:50 后）两个时间点动手。

### I（输入）
- 活跃市值（多头 >4% / 空头 < -2.3%）。
- 量比（开盘集合竞价后；通达信口径，东财需减 1-3）。
- 持仓清单（止损/放飞/滴滴状态）、候选股池（白线之上、黄线之上、N 型/砖型图节奏）。
- 大盘环境（黄线压制、MACD 零轴位置、融资盘密集区、双宽背景）。
- 当日 B1/B2 选股结果（图形 + 量比，不研究 F10）。

### A1（识别）
- **择时**：活跃市值 +4% = 多头（晴天）；-2.3% = 空头（阴天）。
- **玩法节奏**：多头"玩得松"（可重仓满仓轮动）；空头"玩得紧"（只做 B1、轻仓）。
- **复盘三动作**：对每只持仓标注 止损 / 放飞 / 滴滴；只拿白线之上，长线不看。
- **量比三档**：低（<10，震荡）、中（7-16，量价同步上则单边）、高（>20 + 涨 = 攻击日；>20 + 跌 = 稳一手/洗盘）。
- **执行窗口**：开盘集合竞价后 + 尾盘 14:50-14:55。

### A2（决策）
- 择时先行：活跃市值空头则只做 B1、轻仓、甚至空仓；多头可满仓轮动。
- 量比确认：高量比 + 价格上涨 → 跟进买入；高量比 + 价格大跌 → 稳一手，等放量突破日内高点；中量比 + 量价齐升 → 较稳买入。
- 复盘计划：每只持仓开盘前定好次日动作（止损/放飞/滴滴），尾盘前无条件执行（决策 1-1.2 秒，不犹豫）。
- "瞪起来一定要放飞"：两根涨停后必须减仓，盈利不能做亏。
- 大盘：MACD 接近前低极值 + 双宽 + 融资盘承接 → 调整到位可能较大；只允许小幅阴线（≤1%），破位即收紧。

### E（例子）
- 厚普股份：集合竞价量比 3.55 稳一手；第一分钟升至 8.76 立即敲入。
- 某票：开盘量比 22.16 后上攻拉涨停（高量比 + 涨）。
- 航天发展：开盘量比 22 先下杀，放量突破日内高点才走强（高量比 + 跌 → 稳一手）。
- 折纹：B1 次日量比 14.6 高开买入一半，上行补另一半，成本 9.22 收 9.53；冲高放飞 / 破黄线止损 / 破最低滴滴。
- 某 B2：集合竞价量比 12.03，先买一半 5000，突破日内高点量比再抬头补 5000，黄线附近成本。

### B（边界）
- 量比有约 30% 概率出错，只是跟随"铁蝴蝶"（大资金盘前计划、开盘执行），非绝对。
- 中高量比 + 大幅低开加速下杀洗盘的建仓法，普通投资者先不要学（需盘感）。
- 量比口径通达信 vs 东财不同（东财减 1-3），需按软件校准。
- 只拿白线之上的票（长线除外）；黄线之下不碰。
- "选股每天必须做"是为了练盘感，不是每天都买。
- 大盘研判基于双宽 + 融资盘 + 活跃市值假设，若政策/数据突变则失效。

## 三、公式语义 / 指标对齐

- `active_mkt = 活跃市值日变动`；`regime = MULTI if active_mkt > +4% elif BEAR if active_mkt < -2.3%`。
- 量比分级（通达信口径）：`low < 10`、`mid 7-16`、`high > 20`；东财口径 `val_dc = val_tdx - 1~3`。
- 复盘动作三元组：`stop_loss / fangfei(放飞) / didi(滴滴, 破昨低)`。
