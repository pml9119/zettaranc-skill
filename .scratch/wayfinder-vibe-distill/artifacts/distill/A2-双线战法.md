### 3.2 前置判据（不满足则整条战法不适用）

1. **右侧前提**：只做白线在黄线之上的票；股价在黄线之下、或白线仍在黄线之下 → 不看、不用买（回放2 00:19:08、00:27:32、00:39:12）。

3. **流动性前提**：成交额越大技术指标越有效（主力画不了线）；小票易失真（回放2 00:56:56）。
4. **N 型前提**：上涨的 N 型结构不破，循环操作法才成立（回放3 00:03:44；回放2 00:54:08）。
5. **周期前提**：白线金叉黄线打法**周线不适用**（回放2 00:42:28）。

### 3.5 失效与排除条件（不适用清单）

1. **横盘区间**：白黄线优势不显著，改用顶部压力线＋底部支撑线；横盘也不是「碗」（回放2 00:32:40；回放4 00:09:48、00:12:36）。
2. **加速赶顶 / 开口太大**：白线与黄线开口太大不建仓；加速赶顶 + 上方出货大苗子放量不做（回放2 01:08:08、01:08:36）。
3. **图形不完美 / 看不懂**：市场没有唯一正确答案，看不懂就不做，不买不会亏钱（回放3 00:07:28）。
4. **已有出货形态**：双头、大出货、高位长上影、阶梯量次高点放量（回放2 01:27:16、01:42:12；回放4 00:31:44）。
5. **小盘股劝退**：不教抡小票——技术、认知、经验不到位反而亏得更快（回放3 01:05:20）。
6. **港股/低流动性**：港股技术指标普遍不适用、尤其创新药；但成交额足够大的（如队长）可用（回放2 00:25:12–00:25:40、00:57:24–00:58:20）。
7. **仓位硬上限**：单票总仓位不超过十万；买满后「只卖不买」，绝不追加新仓位（回放2 01:48:44–01:49:40）。

### 3.6 元认知层（贯穿四段的框架）

- 战法的目的只有一个：**提供依据**；卖点可从 A 换到 B，但最终必须有一个依据（回放3 00:37:48）。
- 交易多是**模糊的正确**，区间买法就是把模糊的正确量化；最大鸿沟不是买点而是**拿得住**（回放2 01:01:08、01:03:28；回放3 00:58:20）。
- 两根线**不会过时**：只要主力做盘就留下这两条线的轨迹（回放3 00:35:28）。
- 与布林带的区别：布林带是「走出来的」，这两根线是「拿钱画出来的」（回放2 01:04:24）。
- 战法的重要性在选股之上；双线可单独使用（回放1 00:45:16、00:50:24）。
- 大资金玩的是**确定性**；个股要「一等大盘、二等板块、三等太子」，不孤军深入（回放1 01:16:04；回放4 00:23:20、00:23:48）。
