## R（规则）
1. **双线 = 白线 + 黄线两根线构成的操作策略**；是少夫战法（单 BBI 线）之上「加一个维度」的升级。原话 `[1004] 回放2 00:08:52`：「就是就是这两根线啊，一个白线，一个黄线。一个白线，一个黄线啊，这两根线构成了你的一个操作策略。」；`[1004] 回放2 00:11:12`：「双线战法，相当于就是单线战法的往上升级的一个操作」。
2. **白线 = 短期趋势线，可看作流畅波段的「牵牛绳」**，短期快速上涨期一般不破。原话 `[1004] 回放2 00:14:28`：「短期快速上涨时期一般不会跌破白线，因为它是短期的趋势线，可以看作是流畅波段的牵牛绳。」
3. **黄线三属性：主力入场参考线 / 拉升前极限洗盘的极限位 / 大哥控盘成本线**。原话 `[1004] 回放2 00:18:40`：「所以记住这个黄线，又是判断主力是否入场的重要参考线，又是在拉升前最后极限洗盘的一个极限位，同时呢，也是大哥控盘的成本线。」
4. **右侧前提：只做白线在黄线之上的票**。原话 `[1004] 回放2 00:19:08`：「一个是右侧交易的时候只做白线在黄线上的票」。
5. **黄线之下没有交易价值，上涨都是反弹**。原话 `[1004] 回放2 00:27:32`：「黄线之下就没有交易价值，不用买，都是反弹。黄线之下上涨都是反弹，啊，黄线之下都是反弹，不用做。」
6. **放量站上黄线 = 大哥入场，之后考虑 B1 跟进；连续上涨后跌破、次日无法收回 → 中期趋势大概率走坏**。原话 `[1004] 回放2 00:29:52`：「所以记住，连续放量站上，即说明大哥入场。那之后考虑B一跟进。连续上涨后跌破了，次日无法收回，则宣告中期趋势大概率走坏。」
7. **白线金叉黄线 → 上涨趋势确立的概率大 → 等 B1**。原话 `[1004] 回放2 00:41:32`：「第一，白线金叉黄线什么意思？上涨趋势确立的概率大，等。」
8. **白线死叉黄线 = 最后的离场时机，「走错也要走」**。原话 `[1004] 回放2 00:49:56`：「然后第二点啊，白线死叉黄线，那就是反过来嘛。……就是死叉的时候是最后的离场时机，啊，走错也要走。」
9. **要死叉未死叉 + N 型结构不破 + 钩大（幅/负）值 = 极限买点**。原话 `[1004] 回放2 00:54:08`：「白线与黄线要死叉而微死叉时，只要N型结构不破，配合钩大幅值，反而是一个极限买点。」
10. **★ 区间容错买法（本场最核心）**：上涨趋势中白线与黄线区间**任何位置都是容错率较高的买入区**。原话 `[1004] 回放2 00:59:16`：「单行上涨趋势中，白线与黄线区间的位置都是容错率相对较高的买入区。这个我为什么后来教你们双均线法，就是为了解决你们很多人买卖点犹豫不决」。
11. **★ 放量金叉后缩量回踩黄线 = 连续拉升前的最后震仓动作**。原话 `[1004] 回放2 01:15:08`：「下面一个记住：放量金叉后缩量回踩黄线的交易价值非常大。什么意思？往往是连续拉升前的最后震仓动作。」
12. **★ 循环操作法**：加入黄线后从二维升到三维，围绕「B1 买入 → 拿住 → 区间买满 → 放飞 → 跌破白线减仓 → 回区间再接」反复做一只票。原话 `[1004] 回放3 00:08:24`：「所以呢，记住循环操作法，双线的逻辑就是循环操作法。因为加入了一根黄线，双线的循环操作法。……所以呢，你整个的就升维了，从之前的二维变成了三维。」
13. **成交量极小时所有技术都没有意义**（双线失效的前置条件）。原话 `[1004] 回放3 00:36:24`：「是吧？下来以后的这个区间，这个区间没有问题，对不对？就成交量小的，所有的技术都没有意义啊。」
14. **两根线不会过时**：只要主力做盘就留下这两条线的轨迹。原话 `[1004] 回放3 00:35:28`：「刚才啊，我看有朋友问说：'那个说这哥这个两根线会过时吗？不可能啊，只要只要主力做盘。'」

## I（输入）
- K 线序列（识别中长阳 / 长阴 / 跳空 / 长上影）与成交量（放量、缩量、倍量柱、长阴短柱）
- **白线** = 短期趋势线（语料称「牵牛绳」）；**黄线** = 大哥线 / 成本线 / 多空分界
- 白线与黄线的**相对位置**（白线在黄线之上 / 之下）与**交叉状态**（金叉 / 死叉 / 要死叉未死叉）
- KDJ 的 J 值（语料称「钩」），用于极限买点的钩值判据
- **N 型结构**（上涨趋势＝低点抬高 + 高点抬高）；判定见 `[1004] 回放2 01:14:12`
- 成交额 / 流动性量级（用于判技术指标是否有效）
- 周期标记（日线 / 周线，用于排除周线）

## A1（识别）
- **金叉**：白线上穿黄线 → 「上涨趋势确立的概率大」`[1004] 回放2 00:41:32`。
- **死叉**：白线下穿黄线 → 最后离场时机 `[1004] 回放2 00:49:56`。
- **要死叉未死叉**：白黄线将死叉而未死叉 + N 型不破 + 钩大（幅/负）值 `[1004] 回放2 00:54:08`；回放3 复述同一形态并给出区间量化 `[1004] 回放3 01:17:00`：「上面画这个多点连线，三十三十八块七，下面呢是三十二块三毛九。」
- **震仓买点（灾后重建）**：放量金叉 → 缩量回踩黄线 `[1004] 回放2 01:15:08`；止损口径 `[1004] 回放2 01:16:32`：「所以说，第一天跌破黄线，要看第二天能不能拉回来。然后第二天没拉回来，但是这个趋势形成，你可以把这儿设止损。」
- **碗**：异动之后 N 型结构回调形成的区间；**横盘不算碗**。`[1004] 回放4 00:10:16`：「这个一定要记住，今天最核心的就是这个异动之后N型结构异动之后的这个区间，随便，啊，无非是多拿几天而已。」；`[1004] 回放4 00:09:48`：「就是给我记住这个碗啊！给我记住这个碗。同时，这种横盘呢都不是啊，横盘呢都不是」。
- **排除项「躲牛市」**：股价在黄线之下**且**白线也在黄线之下 → 不看。`[1004] 回放2 00:39:12`：「不看，为什么？首先，股价在黄线之下，而且它他妈白线还在黄线之下。不看，不看，不看啊，不看。……这个叫躲牛市。」
- **横盘期间白线黄线无价值**。`[1004] 回放2 00:32:40`：「所以横盘期间，白线跟黄线没有什么价值，没有什么价值。」

## A2（决策）
- **选票三步漏斗**：① 黄线下 + 白线在黄线下 → 不看（躲牛市）→ ② 股价上黄线 + 白线在黄线上 → 关注 → ③ 等 B1。出处 `[1004] 回放2 00:39:12` 起。
- **区间买法的量化执行**（示范）：十万一个仓，逢低一天买一万，打到黄线再加至五万。原话 `[1004] 回放2 01:05:48`：「十万一个仓位，这天买一万，这天买一万，这天买一万，三万会吗？说直接崩上去了，那他妈拿着三万也也赚钱了。」
- **区间买入的止损锚在黄线**。原话 `[1004] 回放2 01:03:56`：「这个区域上你就把黄线设止损。你无非就是亏这样的这样的一个区间。」
- **震仓买点的止损**：第一天跌破黄线不算破，看第二天能否收回；不收回则在黄线下方设止损 `[1004] 回放2 01:16:32`。
- **白线止损**：连续拉升后回踩白线＝第一支撑，破掉则短期趋势大概率走坏。原话 `[1004] 回放2 00:22:24`：「然后连续拉升之后，如果回踩，可以看作是第一支撑。……然后如果破掉，那就宣告短期趋势大概率走坏。」
- **死叉卖出 + 例外**：死叉「走错也要走」`[1004] 回放2 00:49:56`；例外是前面有 N 型结构低点可稍等。原话 `[1004] 回放3 00:37:20`：「然后这块我提醒一下大家啊，就是经常往往说这个在死叉的时候，在死叉的时候，如果前面有N型结构的低点的话，可以稍微再等一等。」
- **真出货判据**：带量长阴（含带量跌停）一律视为真出货。原话 `[1004] 回放3 01:14:12`：「代亮的长音，我说过，这是属于真什么？代亮的长音叫真什么？代亮的长音叫真什么？对，真出货啊！一定要记住，比如说代亮的跌停，不要不要侥幸，就是真出货，就是真出货」〔本句 ASR 明显错乱，照录未改写〕。
- **放飞比例随「碗」大小**。原话 `[1004] 回放3 00:10:16`：「放飞多少？哥们儿新粉是吗？说了无数遍了，你碗大，就慢慢放，十分之一、十分之一放；，如果你碗小，就二分之一、三分之一的放。」
- **心理豁免（承认做不到时的正解）**。原话 `[1004] 回放3 00:03:44`：「说你实在是哥们儿，我我害怕，那个我操，救我卖全卖不做了。你这波桶这儿，这张到这儿赚个百分之十五，可以了，可以了，不做了，休息一个月，可以，行吗？」
- **仓位硬上限（本场口播）**：单票总仓位不超过十万；买满后「只卖不买」，绝不追加新仓位。出处 `[1004] 回放2 01:48:44`–`01:49:40`。
