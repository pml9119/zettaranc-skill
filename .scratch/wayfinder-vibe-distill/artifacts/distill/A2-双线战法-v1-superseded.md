# A2·双线战法（白线/黄线）蒸馏卡

> 语料：20251004 双线战法的核心逻辑（4 段）。notes.md 全读（20-00-33 / 22-00-37 / 00-00-41 / 02-00-45）。
> 主旨：这是体系基本功。从「少夫战法（单 BBI 线）」升级为「白线 + 黄线」双维，解决「确定性非常强的买点问题」，并作为 B1 战法的补充入场依据。

---

## 一、逐段提炼

### 1.1 开场与课程引入（20-00-33 / 22-00-37 前段）
- 双线是基本功，优先级在选股之上；原计划讲 B2 改为双线，因为「双线能解决很多人困惑」。
- 体系传承：少夫战法（单根 BBI）= 基础，双线战法 = Pro 版/下一代，B2（八种战法）＝高阶。基础装与补充装关系；「先打基础，才上 B2」。
- 「上有顶下有底」的横盘震荡区间；「不要怕踏空，也不要怕跌破，只要拿住不动，净值终会创新高」。
- 大盘节奏：慢牛横盘磨人，后段加速（「先慢后快，越来越快」）。

### 1.2 三大率与市场方向（22-00-37 前段）
- 监管发布会反复强调三大率：**波动率**（降至低位→"上有顶下有底"慢牛；极端波动龙队维稳）、**分红率**（历史最高，财政与股权绑定；低波红利是长期策略）、**含科率**（科技市值超银行大金融，新质生产力/科技是十五五第一主线）。

### 1.3 白线/黄线定义（22-00-37）
- **白线（短期趋势线/牵牛绳）**：股价短期快速上涨期一般不会跌破的线；做流畅波段时白线是底线，不能破。
- **黄线（多空线/大哥线）**：判断主力是否入场的标志线。作用三：1) 主力入场标志；2) 极限洗盘的极限位（很多票精确洗到黄线）；3) 主力控盘成本线。主力建仓后通过真实下杀甩跟风盘，但通常不破自己成本线，故触黄线反弹。
- 「技术指标不是保证上涨，而是在不确定市场中提供方向参考和作战依据，提升胜率。」

### 1.4 右侧交易纪律（22-00-37）/ 三道选股步骤
- **只做白线在黄线之上的票**；股价在黄线下或白线在黄线下 → 直接放弃（不看），避免浪费时间。
- 左侧（看估值，如净值 vs 股价）vs 右侧（趋势交易，必须白线在黄线上）。
- 选股三步：① 不看黄线之下、且白线在黄线下的票（躲牛市）；② 直到股价站上黄线、同时白线金叉黄线 → 入观察池；③ 观察池里等 B1 买点（回踩确认）。
- 短期放量站上白线＝具备上涨爆发力前提；连续拉升后回踩白线＝第一支撑，跌破则短期趋势大概率走坏，应全清。
- 走完一波跌破白线必须全清；其后新买点是一笔全新交易，不混淆。

### 1.5 核心玩法（22-00-37）
- **玩法一 · 金叉/死叉**：白线金叉黄线＝上涨趋势确立概率大 → 可「拿到死叉」的大傻子玩法（吃满整波）；白线死叉黄线＝最后离场时机，「走错也要走」（主力弃盘、赌场关门）。
- **玩法二 · 要死叉未死叉的极限买点**：白线与黄线将死叉而未死叉，N 型结构不破，配合钩大负值 → 极限买点（例：宁德时代、队长港股）。流动性越大的票技术指标越有效（主力难以画线）。
- **玩法三 · N 型上涨的白黄线区间买法（最核心）**：白线在黄线上且 N 型向上，区间内任何位置都是容错率高的买入区，不必强求具体 B1（解决"没买点、涨上去了"的焦虑）；可分批建仓（十万仓逢低买一万，再跌再买一万）。排除项：横盘区间、加速赶顶（开口太大）、出货大苗子（放量大阴/长上影）。止损：跌破黄线。
- **玩法四 · 放量金叉后缩量回踩黄线＝震仓买点**：真金白银砸盘逼下车，但成交量极度萎缩（长阴短柱）；次日能收回视为有效，黄线下方设止损。赌的是"最后一跌"，不破黄线是主升起点，破则止损空间有限（盈亏比高）。

### 1.6 循环操作法（00-00-41 前段）——综合应用题
- 核心流程：B1 点（白黄线放量金叉）买入 → 横盘/温和上涨拿住 → 进入白黄线区间时加仓买满 → 脱离成本区放飞（分批止盈）→ 某天跌破白线减仓，但顶部无量、主力未出货，跌回白黄线区间可加回来继续循环。
- N 型结构不破是前提：到 B1 就"抡"，跌漏回白黄线区间继续买，起来加速就放飞，没到顶部再加仓，反复做。
- 数学题类比：严格按流程可拆开做（先卖后买回），也可合并直接买。实在害怕就卖光离场休息，赚 15% 收手，完全不做的结果也对。

### 1.7 升维与"碗"（00-00-41 后段 / 02-00-45）
- 加入黄线后战法从二维升到三维，看市场视野不同；以后任何牛股不纠结完美 B1，进"碗"（白黄线区间）即可买，剩下解决拿不拿得住。
- **碗（核心交易图形）**＝异动之后 N 型结构回调的碗；横盘不是买点；只有 N 型起来后回调形成的"碗"才值得关注。黄线位置震仓是标准形态（一根下来一根上去，或两根都下但低点不破前低），震仓后往往加速。
- 反面教材：横盘无明显放量异动不做；无供图（无资金/无量）不做；已加速翻倍的图不做。

### 1.8 案例与细节（00-00-41 / 02-00-45）
- 八一钢铁＝标准案例：B1/B2 都可买，放量金叉→缩量回调进"碗"→放量涨停；有"呼吸节奏"，非庄股。庄股特征＝缩量涨停后跟放量大阴。
- 华丰化学放飞补充：碗大慢慢放（十分之一），碗小二分/三分之一，碗特小全卖。
- 某股 B1 位 4.48/5.18，上方两线 44.46/43.69，进入区间即买点，之后拿白线死磕（牵牛绳）。
- **带量长阴＝真出货**（跳空往下、放量杀跌），对散户所有带量长阴都是真出货，不要侥幸。
- 顺大势：板块龙头（阿信/中信证券等）没表态，个股连续突突则板块结束；回档是健康换手，怕就卖、信就拿着。
- 指数贡献/入阁：新调入指数的票被指数基金被动配置（天然接盘者），入阁后半年到一年大概率 30%-50% 确定行情，早涨晚涨都会涨（"新人带旧人"）；等它大幅回调后白线站上黄线放量（大哥来了）按 B1 入。
- 纯血标的：业务清晰、名字直白（北方铜业=铜、赛力斯=问界）更易被大资金看懂，出货方便；概念股老熟人（方正、特瑞德等）什么热蹭什么，看不懂不做。
- 红肥绿瘦：用红绿柱面积判断多空；区间内红柱面积大且高＝没有理由看空；高位绿柱面积大＝获利了结。

## 二、RIA 能力卡（双线战法 · 关键字段对齐）

### R（规则）
双线战法＝在少夫战法（单 BBI 线）之上增加黄线，用**白线（牵牛绳/短期趋势线）＋黄线（大哥线/多空线/成本线）**双维判断趋势与买卖点。核心是对 B1 买点的增强与容错：不纠结完美 B1，只要白线在黄线之上且 N 型向上，白黄线区间即为容错买入区。**右侧纪律＝只做白线在黄线之上的票。**

### I（输入）
- 白线（短期均线）与黄线（多空/成本均线）两条线。
- 白线是否在黄线上方（右侧前提）；股价相对两线的位置（线上/线中/线下）。
- N 型结构（低点抬高、高点抬高）；"要死叉未死叉"形态（白线将下穿黄线但未形成死叉）。
- 量价：放量金叉、缩量回踩黄线（长阴短柱）、放量长阴（出货大苗子）、红肥绿瘦（红绿柱面积）。
- 环境：大盘"上有顶下有底"、活跃市值多空区间、板块龙头是否表态。

### A1（识别）
- **可操作**：白线在黄线之上（右侧）；股价站上黄线且白线金叉黄线 → 进入观察池。
- **买点**：① 白黄线区间（容错买点，不需完美 B1）；② 要死叉未死叉＋N 型不破＋钩大负值（极限买点）；③ 放量金叉后缩量回踩黄线（震仓买点）；④ 进入"碗"区（N 型回调低点区）。
- **戒除**：黄线之下/白线在黄线下的一切上涨视为反弹，不参与；横盘区间不适用；加速赶顶（开口太大）不做；出货大苗子不参与；横盘无明显异动不做；已加速翻倍不做。
- **卖点**：跌破白线（第一支撑失守，全清）；白线死叉黄线（最后离场，走错也要走）；带量长阴＝真出货。

### A2（决策）
- 右侧纪律：白线在黄线下 → 不看、放弃；只做白线在黄线之上的票。
- 金叉买、死叉卖（大傻子玩法从金叉拿到死叉；大资金掐头去尾做波段中间利润）。
- 区间容错买：白线在黄线上 + N 型向上，区间内任何位置可分批建仓，止损看黄线。
- 循环操作：B1 抡 → 区间加仓满 → 脱离成本放飞 → 破白线减仓 → 顶部无量未出货则跌回区间补回，反复做；怕就卖光休息。
- 流动性越大越有效（主力难画线）；小盘/港股画线容易、指标易失真。
- 止损位设在黄线或 N 型前低；跌破即走（只输一根线）。

### E（例子）
- 300002 选股：站上黄线＋白线金叉→观察池→等 B1 回踩。
- 八一钢铁：放量金叉→缩量回调进碗→放量涨停（标准非庄股）。
- 宁德时代、队长（港股，200 亿日成交）：要死叉未死叉极限买点。
- 国防 ETF：白黄线"要死不死"＋N 型不破＋钩大负值→站回黄线持有，跌破黄线卖。
- 某股 B1 4.48/5.18，两线 44.46/43.69，进区间即买点，拿白线死磕。
- 小米/米尔：上腰顶下腰底，注重大哥增持回购态度（金额不重要，传递"放心"信号）。
- 国泰海通：稳定币被拍，一拉就有上方套牢盘砸盘，白线在黄线下，走势弱。

### B（边界）
- 横盘震荡区间双线优势不显著，应改用顶部压力线/底部支撑线（如赛力斯特定区间）。
- 加速赶顶、缺口过大（白黄线距离远）时开口风险高；不买开口过大的区间，等回落至黄线附近或缩量回踩。
- 流动性差的小盘/港股技术指标易失真。
- 空头区间（黄线之上但整体空头）下仅作反弹离场参考；无增量资金（活跃市值空头）时胜率降。
- 双线解决买点与"拿得住"，需配合仓位与纪律；不预测点位，只识别概率。

## 三、公式语义 / 指标对齐说明

- 双线在 Z 哥体系中有两套语境：① **均线系**：代码引擎 `BBI` 为"少夫线"，`MA` 白/黄线；② **MACD 系**（indicators.md 3.12）：白线 = DIF/DEA 之一，黄线 = DEA 对应股价。A2 双线战法与 MACD 系共享"白线/黄线"命名，但因语料以"均线白/黄"为主，本卡按**均线双线**归纳，与 indicators.md 的 MACD 双线互为 also_read。
- 关键判定布尔化（便于回测映射）：`right_side = 白线 > 黄线`；`in_xianqu = 白线>黄线 AND 股价 处于 [黄线, 白线]`；`yao_si_wei_si = 白线将下穿黄线(未穿) AND N型不破`；`zhen_cang = 放量金叉后缩量回踩黄线(长阴短柱)`；`died_poxian = 收盘 跌破 白线`；`gold_cross / death_cross` 标准定义。
