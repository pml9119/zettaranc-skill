## 卡一 · B1/B2/B3 三件套确认体系

> 模块 M1 ｜ 来源段：`[1006]` 回放1 / 回放2 / 回放3、`[0107]` 回放2
> 「三件套」是 Z 哥在 20251006 明确命名并当场交付的核心概念（`[1006] 回放1 01:51:04`「你就记住，以后管这个就叫三件套。咱家的说法，记住吗？叫三件套。」）。

### R（规则）
1. **B1 = 不同时间周期下的阶段性低点**；判据是 KDJ 的 J 值（语料称「钩」）打到超卖区。原话 `[1006] 回放1 01:43:08`：「日线级别的KDJ的钩，往下打到十三以下都算是B一啊，都算是B一。」
2. **B2 = 确认 B1 低点的那根阳线的位置，且必须接在 B1 之后**，不能是凭空一根突破阳线。原话 `[1006] 回放1 01:43:36`：「就是B二一定是接着B一，一定要记住啊，B二一定接的是B一，而不是凭空来一根突破，就或者大阳线就就是B二。」
3. **B3 = B2 那根放量中长阳之后的一根（小）阳线**，即上涨途中的中继买点；**没有 B4/B5**。原话 `[1006] 回放1 01:45:28`：「B四、B五就没了，咱们就不再讲了。那他妈就是属于瞎瞎芝麻追了啊。」
4. **三件套 = B1 → B2 → B3 依次确认**；三根形态完美则大概率进入沿白线上涨的流畅趋势。原话 `[1006] 回放1 01:45:56`：「这三根合起来，如果形态很完美的话，大概率你会进入到一个非常流畅的沿着白线上涨的一波趋势当中。」
5. **失败三路径**：B1 之后不来 B2（且连续 B1 说明不确定性极大）／B2 出来后一根阴包阳把 B2 打掉、没出 B3／B3 根本没出现。出处 `[1006] 回放1 01:46:24`—`01:46:52`。
6. **三维排名（互相独立，不可混用）**：盈亏比 **B1 > B2 > B3**；止损幅度 **B2 最大 > B3 > B1 最小**；**上涨确定性 B3 最高**（语料原话 `[1006] 回放2 00:01:24`「B三反而是最大的」）。
7. **B1 的唯一硬性否证条件：必须缩量**。原话 `[0107] 回放2 01:46:52`：「咱们的B一是缩量，永远要记住这个啊。」

### I（输入）
- K 线 close/high/low/open 与成交量序列（vol）
- KDJ 参数 (9,3,3) 的 **J 值**（语料称「钩」）
- 白线 `EMA(EMA(C,10),10)`、黄线/大哥线（4 参数 BBI 变体）—— 引自 `knowledge/trend-lines.md:20-21`
- 放量 / 缩量：语料给的是相对口径 —— `[1015] 回放1 01:59:28`：「他要比他高，这叫放量。他要比他低叫缩量。他比他低那么多，这叫极致缩量啊！」
- 涨跌幅与涨停性质（10cm / 20cm / 30cm）
- B1 当日是否缩量（用于 R7 的否证）

### A1（识别）
- **B1**：日线 J 打到 13 以下即为「日线级别的 B1」；周线打到此值即周线级别；月线同理。出处 `[1006] 回放1 01:42:40`、`01:43:08`。
- **B2**：B1（或 SB1）之后出现一根**中阳线**，且 J 值明显向上拐头。语料给的拐头例子：`[1006] 回放1 01:45:00`「比如说钩打到十，出现这根阳线了，往上拐了，这也叫B二。钩打到负十四，突然间出现一根啪折线的那种钩上翘啊，这个也叫B二。」
- **B3**：B2 那根放量中长阳之后再一根小阳线；**允许变体** —— B3 可以直接接长阳，但长阳之后必须再接一根小阳线。出处 `[1006] 回放1 01:52:00`。
- **原理（为什么必须三根）**：底分型不稳定、必须靠 B3 确认；主力若要连续 N 型结构上涨，不可能在低位停留太久让低位卖出的人再抄回来。出处 `[1006] 回放1 01:52:56`：「底分型不稳定啊，底分型必须靠B三才能确认。」
- **B2 阳线的二次验证**：上影线要小、要放量，且次日**不该收回**；次日若是阴线，说明当天那根大概率是上影线。出处 `[1006] 回放1 01:53:24`。

### A2（决策）
- **持有检验期**：买入后**三天内**检验能否成三件套。原话 `[1006] 回放1 01:51:32`：「说你要连三件套都没成，那你就不要对他有什么预期。甚至说可以把仓位该减就减下来，就不要给他浪费时间了。」
- **B1 的走势期待**：三个交易日内恢复上涨，至少不跌。出处 `[1006] 回放2 00:16:20`。
- **B2 的走势期待（最严）**：两个交易日内必须大幅拉升，只允许休整一天，**买入当天即算第一天**；「两天不涨卖一半」给它第三天，第四天视为衰竭。出处 `[1006] 回放2 00:17:44`、`00:20:04`、`00:21:00`。
- **B3 的持有方式**：不破止损位就一直拿，语料称之「钝感力」。出处 `[1006] 回放2 00:21:28`。
- **买入时点**：B1/B2/B3 所有玩法均**次日开盘**买入。出处 `[1006] 回放2 00:47:36`。
- **止损位**：B1 = 买入 K 线低点 / N 型结构前低 / 结合白线；B3 = 这根 K 线的低点，或这根大阳线的中间值（两个候选，语料**未给唯一答案**）。出处 `[1006] 回放1 01:56:40`、`01:57:08`；`[1006] 回放3 00:17:16`—`00:18:12` 的「只输一根」；`[1006] 回放3 01:18:52` B2/B3 均**收盘止损**。
- **仓位原则**：B1 **可以**开超市（分散买），B2 **不建议**开超市（成本高、盈亏比不如 B1）。出处 `[1006] 回放3 01:46:24`。

### E（例子）
- **紫金矿业（语料原文点名）**：`[1006] 回放1 01:57:08`「你把止损设在二十一块六，啊，说二十一块六，那后面你会看到它直接上去，那盈亏比也是非常高的，对吧？二十一块六涨到二十九块八」——止损未触发、B3 正例。
- **登云（语料原文点名）**：`[1006] 回放1 01:57:36` 最简版识别口诀「你看这天不B一吗？这天B一吧，这天B二吧，小阳线是不是B三？三件套一凑齐，哎呦喂，牛逼！」
- **新风光（语料原文点名）**：止损 33 / 36.7 未被打到 → 涨到 42.58。出处 `[1006] 回放1 01:58:04`。
- **硅宝科技（语料原文点名）**：止损 22.7 被打掉 → 反例。出处 `[1006] 回放1 01:59:00`。
- **未指名个案**：止损设 53.9（K 线低点往下三到）或 53.3（大阳线中间值），两点都破、亏 7%，不走则亏 17%。出处 `[1006] 回放1 01:59:28` —— 这是「止损位选择直接决定盈亏比」的量化演示。
- **「安德烈」（语料原文代称，未核实）**：B1 因**是放量 B1** 被判定不参与（`[0107] 回放2 01:46:24`、`01:47:20`、`01:48:16` 连续三次），印证 R7。

### B（边界）
- **B3 的盈亏比是「不确定」而非「低」**。原话 `[1006] 回放1 01:56:12`：「记住，不是严格意义上来讲，不是指B三的盈亏比低，而是指B三的盈亏比不确定。」原因：大盘不好 / 板块突发效应 / 主力做盘 / 还在区间内没突破 / 假突破又下来。
- **三件套不具普适性**：完美形态可遇不可求。出处 `[1006] 回放1 01:59:56`。
- **B2 的钩值门槛在 0107 被当场放宽**（与 1006 的「钩<55」冲突，**并列记录**）：`[0107] 回放2 01:00:40` 钩<55 → `01:02:04` 六十五也行 → `01:02:32` 改 64 → `01:03:00`「原则上小于八十都可以」→ `01:04:24` 定调 80；本人自述 55 是「怕你们追」的人为收紧（`01:03:28`）。**两套口径并列，不单方面取舍。**
- **1006 段内三处未定论**：B3 止损位二选一未定（`[1006] 回放1 01:57:08`）；B1 图形数量「十张图 vs 四种」两说（`[1006] 回放3 00:59:44` vs `01:00:12`，本人自述记不清）；战法编号体系四套说法并存。
- **止损位候选不唯一**：语料同时给出「买入 K 线低点 / N 型结构前低 / 横盘平台下沿 / 大阳线中间值 / K 线低点往下三到」多个候选，**未给优先级排序**。
- **不适用市场**：关键K 与双线体系在 T+0 市场（港股 / 美股）不适用（见卡四 · B）。

## 卡二 · B2 三大暴力图形（平行重炮 / 灾后重建 / 跃跃欲试）

> 模块 M1 ｜ 来源段：`[1006]` 回放2 / 回放3、`[0107]` 回放2
> 语料在 1006 明确「三大暴力图形」为一场课的主题；0107 复述其判定条件。

### R（规则）
1. **平行重炮 = 两根起的平行放量大阳线**；三根叫三门重炮，两根叫双枪，一根不算。原话 `[1006] 回放2 00:52:16`：「什么叫平行重炮？就是两根起，两根起，平行重炮，两根起，两根大阳线，两根起，这叫平行重炮。说三根行不行？肯定行啊，三门重炮。」
2. **灾后重建 = 放量金叉后缩量回踩黄线**，是连续拉升前的最后震仓。原话 `[1006] 回放3 00:04:40`：「放量金叉后缩量回踩黄线的交易价值非常大」。
3. **跃跃欲试 = 横盘期间放量大涨、红长绿短、红肥绿瘦**，越往后越「箭在弦上」，总有一次是真突破。
4. **没有 B2，一切 B1 都是空中楼阁** —— 这是语料给出的最强判据。原话 `[1006] 回放3 00:10:16`：「没有B二，那一切的B一都是空中楼阁。」
5. **确认信号统一为「一根放量中长阳」**：灾后重建踩完黄线后来一根放量中长阳，一举同时确认 B1 与黄线支撑。出处 `[1006] 回放3 00:05:36`。
6. **「横盘不看线」与「白线必须在黄线之上」并存，语料给出折中解**：横盘 / 震荡期不看线作为原则没问题，但这类票应放自选当「胚子」，真正入场仍需白线上穿黄线。出处 `[1006] 回放3 00:49:56`、`01:48:44`。

### I（输入）
- K 线序列（识别大阳线、长阳、小阳线）
- 成交量（放量 / 倍量柱 / 缩量 / 阶梯量）
- 黄线（大哥线 / 成本线）位置、白线与黄线的相对关系
- 横盘区间的高低点（画线用）
- 涨停 / 大阳线实体幅度
- 是否「击穿对手盘」（跌破黄线后收回）

### A1（识别）
- **平行重炮**：相对平行位置的两根及以上放量长阳；「双枪」是两根的别称。出处 `[1006] 回放2 00:52:16`、`00:54:36`。
- **灾后重建完整标准**（Z 哥在原话中自标「往往是最后的震仓」）：`[1006] 回放3 00:28:00`：「往往在连续拉升、放量拉升、缩量下跌，然后赶着配合大盘的一波调整，它快速的缩量打到黄线、大割线〔大格线〕。记住，往往是最后的震仓」。
- **跃跃欲试**：横盘期间放量大涨、红长绿短、红肥绿瘦；最漂亮的构造是**股价不变、主力把白线调整到黄线之上**（趋势已变、价格未变）。出处 `[1006] 回放3 00:49:00`。
- **低位 / 高位的量化定义**（语料给出的明确口径）：`[1006] 回放3 00:23:48`—`00:24:16`：**在黄线区域、碗的上下区间内波动 = 低位**（黄线 = 大哥成本区）；**离黄线 30%–40% = 高位；高位放量都不是好事**。
- **高度控盘的唯一解**：长期横盘 + 量极度萎缩 = 完全空盘且未出货。出处 `[1006] 回放3 00:21:56`。
- **0107 复述的三图形识别条件**：平行重炮（`[0107] 回放2 00:47:08`：两根同位置 + 两阳加一堆缩量阴）；灾后重建（`00:49:28`：击穿对手盘 + 黄线倍量柱接筹码）；跃跃欲试（`00:51:48`：红长绿短 → 阶梯量缩量 → 破 N 型前低击穿对手盘，但**无倍量柱则不启动**，`00:52:16`、`00:52:44`）。

### A2（决策）
- **平行重炮的用法**：在相对底部区间出现才有意义（高位横盘放量未必好）；等回踩黄线（牵牛绳）是「极限买点」，破黄线止损。
- **灾后重建**：确认后可直接跟进；B1 确定性不高、**必须等 B2 放量确认**。出处 `[1006] 回放3 00:05:36`。
- **跃跃欲试**：买点 = 钩拐头向上 + 一根中长阳放量；止损设区间相对低点 / N 型低点；横盘期重点看量价与红肥绿瘦；**横盘后破位下跌 = 出货**。
- **量能判据的简化（0107 明确修正）**：黄线位置反包**只需要看那两根的关系**。原话 `[0107] 回放3 01:01:36`：「记住，黄线位置反包，你只需要看他们俩的关系就行了，不要看前面的，也不要看背量〔倍量〕。」
- **出货量级门槛**：半量 vs 四分之三量是判出货的门槛。原话 `[1006] 回放4 00:10:16`：「半量，这就连四分之三都不是。……所以说这都不是四分之三量线，就不显著」。
- **目标价「填坑」算法**：`现价 +（现价 − 起点）`，两例现场口算：730−170+730=1290；428−202+428=654（654 恰为该票历史最高点）。出处 `[1006] 回放4 00:23:48`、`00:24:44`。
- **B2 完整「标配」要素链**（0107 收口）：原话 `[0107] 回放3 00:38:44`：「顶部无量，长阴短柱，打到黄线，击穿对手盘，打到黄线，灾后重建，多倍亮柱〔倍量柱〕，起来，中中中中长阳……这就属于那个标配了。」

### E（例子）
- **平行重炮实例**：`[1006] 回放2 00:54:36`「打上黄线，大哥线带亮的，放亮的，看了吗？对吧？对，双枪啊，双枪是不是两根儿？是不是两门重炮叫双枪？」
- **灾后重建实例（京科科技 / 荆轲）**：`[1006] 回放3 00:06:04` 作「京科科技」、`00:09:20` 作「荆轲」——**ASR 同一票两种写法，未核实**。
- **跃跃欲试实例**：赛赛、潮宏基、新汉新材（均为语料原文点名）。
- **反面：绿肥红瘦 = 出货区**，与「红肥绿瘦 = 建仓」含义**相反，不可互换**。原话 `[1006] 回放4 00:27:32`：「所以它在这个空间之内，你看是不是绿肥红瘦，在这个位置出货，啊，很标准，所以这他妈就是内地的麒麟会做的啊，很标准手法。」
- **潮宏基（语料原文点名）**：横盘三个月、一根 7.17 倍量柱能干。出处 `[0107] 回放2 00:11:40`—`00:16:48`。

### B（边界）
- **倍量柱到底是否必需 —— 语料内部张力，并列记录**：支持必需见 `[0107] 回放3 01:03:00`「不是倍量柱我就不敢抡重仓」；支持非必需见 `[0107] 回放3 01:01:36`（只看两根量关系）与 `[0107] 回放2 00:49:56` 中煤能源「不是倍量柱，但也还好」仍进。
- **「事不过三」只适用于横盘突破，不适用于下跌趋势**：语料指出「横久必跌」仅适用于下跌 / 震荡趋势，牛市应记「横有多长，树有多高」；并明确**顺口溜不可靠**。
- **位置决定放量的解读方向相反**：相对底部区间的放量长阳 = 庄家建仓；高位翻倍后的放量（阴阳皆然）= 分歧。出处 `[1006] 回放2 01:03:28`。
- **英菲特案例在段内被本人当场重新归类**（`00:11:40` 双依据 → `00:51:20` 取消横盘依据，只留灾后重建）——**语料内部修订，按后说记录**。
- **图形可逆性**：重炮倒过来 = 期货 5/15 分钟做空形态。出处 `[1006] 回放3 00:26:36`。
- **「无上影线最好」是强偏好而非硬门槛**：`01:14:12` 列为条件 → `01:25:52` 说有上影也行 → `01:26:20` 又说不是什么上影都行 → `01:56:12` 却以此放弃 80 分图。**强度层级存疑，语料未定论。**
- **图形判据的自相矛盾处照录**：`[1006] 回放2 00:04:12`「B三你要对应的是四分之三阴量线」与 `00:06:04`「四分之三阳量线，你要把它当成一个b三买点」**互斥**，疑 ASR 漏字，**并列记录未取舍**。

## 卡三 · B2 选股条件与综合判断

> 模块 M1 ｜ 来源段：`[1006]` 回放2 / 回放3、`[0107]` 回放2 / 回放3

### R（规则）
