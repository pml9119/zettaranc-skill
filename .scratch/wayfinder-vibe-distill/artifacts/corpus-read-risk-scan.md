## 一、方法（含**两次自我纠错**）

### 1.1 v1 指标缺陷：时间覆盖率假阳性

用正则 `\(HH:MM:SS - HH:MM:SS\)` 求 notes 覆盖时长 → 对**格式不同的正常 notes 误报 0%**（B 类虚高到 24 段且大多 notes 有 30KB）。

**修正**：改用「**notes 最大时间戳 / transcript 最大时间戳**」，不依赖分段格式，只要求 notes 有时间戳。

### 1.2 v2 分级缺陷：把「成品笔记」误判为「整篇推理稿」（★ 由 A2 子代理质疑触发）

**原判定**：`推理稿特征(首 2 行) AND 小节数 == 0` → A 类

**缺陷**：小节数正则写作 `^#+\s*\[`（**要求标题后紧跟方括号**，如 `### [标题](时间)`）。
但实际笔记有多种格式：
```
### [段落标题] (00:00:00 - ...)      ← 我的正则能识别
### 段落1: 开场：让观众默念标的 (00:00:00 - ...)   ← 标题后是文字，我的正则漏计
### 历史走势与当前回调位置 (00:00:00 - 00:02:20)   ← 同上
```
→ **7 个成品笔记被误判为「整篇推理稿」**（它们首行有生成叙述，但正文是**完整的结构化笔记**）。

**修正**：
- 标题计数改用**宽口径** `^#+\s*\S`（任意标题）
- 分级拆为三级：`A`（有生成叙述 **且标题数 = 0**）/ `A1`（有生成叙述 **但标题数 > 0**）

### 1.3 两次纠错的实际影响

| 口径 | A 类（推理稿） | 说明 |
|---|---|---|
| v1 | 17 段 | ❌ **高估** |
| **修正后** | **10 段** | ✅ 真·草稿（标题数 = 0） |
| 新识别 | +19 段 A1 | 成品笔记，仅首行污染 → **处置完全不同** |

**这 7 个被误判的段**（实为成品笔记，标题数 6–25）：
`20250423第五部分`(25) / `2026-04-04第3部分`(15) / `20260429摸底考 01-29-41`(13) / `20251231击穿对手盘 回放3`(10) / `2026-04-04第3部分前`(9) / `20250917主力出货 22-01-18`(7) / `20251119知行合一 回放`(6)

