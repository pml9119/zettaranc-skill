## 消费规则

- 写 spec、票、代码与注释时**一律使用 `GLOSSARY.md` 的词汇**
- 领域已有**裁定的同义组与一词两义**，改名词前先查 map.md 的术语条目：

| 类型 | 内容 |
|---|---|
| 同义组 | `专精图 ≡ 砖型图 ≡ 砖形图`；ASR 变体另有 `专行图/专情图/专型图/专赢图/专景图` |
| 同义组 | `¾阴量线 ≡ 四分之三阴量线 ≡ 四分之一量线` |
| **一词两义** | `黄金` —— 语料中 = **黄线**；公式中 = **黄色柱** → 字段命名必须消歧 |
| **一词两义** | `多空线` —— 图中 = `calculate_dg_yellow`（**黄线**）；另有序境概念「活跃市值多空区间」 |

- 难以逆转的决策落成 ADR：`docs/adr/NNNN-<slug>.md`，走 `/domain-modeling`

## 已识别的缺口

`GLOSSARY.md` 是**下游依赖但尚未存在的文件**。map.md 明确要求别名表**同时**进三处：

```
GLOSSARY.md  +  knowledge/ 检索说明  +  module-lexicon.tsv
```

漏任何一处就会两头失真：语料侧漏检、knowledge 侧虚高缺口 —— 这是同一个根因的两面（已发现四例假缺口）。

在它建立之前，术语以 `artifacts/module-lexicon-synset.tsv`（**123 组同义词组**）与 map.md 的术语条目为准。
