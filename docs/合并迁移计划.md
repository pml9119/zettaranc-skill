| 风险 | 对策 |
|------|------|
| ZK 自有 A 股信号口径（b1/b2 公式）与我们略有差异，YAML 规则值域不匹配 | P2 全量做 `rule_yaml` 字段表 diff；跑 ZK 真实数据 + 我们 regression 集对拍（`regression_runner`） |
